Add it to Gmail (2 minutes)

  1. Click Copy signature above (on a laptop, in Chrome).
  2. Gmail → gear icon → See all settings → General → Signature → Create new, name it "Main".
  3. Click in the box, press ⌘V. The photo and button should appear.
  4. Under Signature defaults, set it for new emails and replies. Scroll down, Save changes.

Outlook: Settings → Mail → Compose and reply → Email signature → paste. Apple Mail: paste into Settings → Signatures, then untick "Always match my default message font".
iPhone Gmail app: signatures there are plain text only, so it will show your name and links, not the design.
